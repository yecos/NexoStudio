# Image Library

Folder structure for public visual assets:

- `brand/`: Nexo Studio logos and brand marks.
- `hero/`: first-viewport and social preview imagery.
- `services/`: service and contact section images.
- `projects/`: portfolio and case study imagery.
- `team/`: team portraits.
- `brochure/`: exported brochure pages and supporting sales visuals.

Keep new assets in the closest folder by use case. Prefer descriptive filenames for future additions.
